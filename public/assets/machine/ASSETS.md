# Asset provenance

The GLB in this directory contains project-authored geometry and animation, plus fictional AI-generated photographic panes. It contains no television footage. The runtime replaces selected panes with the application's licensed archive videos. Original geometry, animation and generated still assets are covered by the root MIT licence to the extent the project can license them; that grant does not assert exclusive rights in generated output or grant third-party trademark rights.

Recorded footage in `../../media/` is excluded from MIT. Each feed's `CREDITS.txt` identifies its source, licence, modifications and available hashes. The core feeds use MEVA (Kitware/IARPA, CC BY 4.0), Mixkit Free stock, and public-domain DVIDS/NASA recordings. City feeds use Pexels or Mixkit Free licences. These clips are bundled as part of this interactive application, not offered as an independent stock library. Observe their licences if extracting or republishing them.

Natural Earth coastline, land, boundaries and settlement data in `../globe/` are public domain, documented in that directory's provenance JSON files. Decorative lights and routes are authored visual effects, not real-time measurements.

The scene was produced using Unity and Blender. Synthetic stills were produced using OpenAI image generation. Original embedded content credentials are retained where present.

Dependencies retain their upstream licences. Only installed system fonts are requested; font files are not bundled. This unofficial interface is not affiliated with or endorsed by the Person of Interest production, footage contributors or dataset providers.
